##Project name
-----------------------------
My Project Name is FitLog.

##Short description
---------------------------------
This is a personal fitness tracker website. It's help to continue our exercise and build our body strong by calory eating concept. It's tracked our daily fitness, calculate exercise duration, time, calory gain and burn etc. It's a like of personal mentor in our healthy life. 

##Technologies used
------------------------------
1) NPM 
2) Next-js framework
3) Daisy UI 
4) React library in next-js
5) React icons , toastify 
6) App router etc.


##5 key features of the project
----------------------------------------

1) User Interactivity 
2) Onclick show toastify meassage 
3) Dynamic Routing
4) Using context Data use without Propsdrilling in all time 
5) Dynamic calculation, delete , sorting etc.
